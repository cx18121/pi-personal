# Delegation

Delegate a bounded question when another agent adds useful independent judgment or can investigate a separable part of the task. Keep the active parent model. Model choices and waiting behavior are owned by the installed model-policy and subagent extensions.

Use the first available permitted preference from the current model policy. Prefer a complementary family for an independent challenge. A fresh same-family reviewer is a reasonable fallback when necessary, with that limitation disclosed. It does not satisfy an explicitly cross-family experiment. Report provider failures and use the next permitted fallback rather than changing persistent settings.

Give the child the question, exact working directory and source locations, intended result, and relevant context it cannot recover itself. State its authority. Review and investigation children are read only. Include project rules or their owning paths because children do not automatically inherit them. Point to primary sources rather than copying a persuasive account of the work.

For repository reconnaissance, ask for the entry points, data flow, related implementations, and important unknowns relevant to the decision. The parent reads the load-bearing source before acting on the result.

The parent owns synthesis, consequential choices, and project mutations. Continue independent work while the child runs. If nothing useful remains, return control and resume when its result arrives.
